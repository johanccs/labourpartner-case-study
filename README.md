# LabourPartner — Case Study

**→ [johanccs.github.io/labourpartner-case-study](https://johanccs.github.io/labourpartner-case-study)**

LabourPartner is a labour-relations compliance platform that guides South African
employers through discipline, grievance and dismissal procedures, producing
documentation that holds up when it is challenged.

## Why isn't the source here?

LabourPartner is a private commercial product. Its application source — an
ASP.NET Core API and an Angular client — is not published, and this repository
does not contain it. What's here is the public case study: the problem the
product solves, how it is built, the decisions behind it, and its known
limitations.

## What's in this repository

`docs/` holds the published site. GitHub Pages serves that folder directly —
there is no build step.

The site is hand-written HTML and one stylesheet, with no dependencies, no
bundler and no external assets. What is committed is what is served.
